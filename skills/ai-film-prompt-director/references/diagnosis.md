# 失败诊断

先记录素材来源、观察到的时间点和现象；未获取画面或音轨则只引用用户反馈。区分观察、可能原因和验证方案，不把假设写成定论。对单次失败避免泛化，必要时同条件多次对照，记录模型、版本、时长、输入资产、参数及随机性。

| 候选根因 | 判断线索 | 最小验证或修复 |
|---|---|---|
| 角色资产不足 | 多角度身份漂移、侧背缺参考 | 补正侧背、露齿或声音资产；保持提示词不变对照 |
| 表达不准确 | 动作顺序/对象未指明 | 指明主体、触发、先后；单变量重试 |
| 指令冲突 | 同时要求对立景别、时长或动作 | 找出原句并说明，按已确定优先级处理；不能猜时询问 |
| 镜头设计 | 运镜遮挡关键动作、轴线不明 | 给不改变剧情的机位/拆镜方案，结构变更需用户决定 |
| 时长不足 | 对白和连续动作挤在短时段 | 估算节奏，提出延长/拆段选项，不静默改时长 |
| 模型能力 | 简化后仍失败或功能不支持 | 查具体版本能力；改工作流、分段或合成，不假设上限 |
| 声音生成 | 口音、声音身份、气声或口型不稳 | 固定声音参考、多情绪试音，按条件分离音画同步 |
| 视频时序/物理 | 跳帧、道具瞬移、空间或发丝断裂 | 固定起止状态、参照与轴线，分段测试及剪辑衔接 |

通常只调整一个变量并比较；必要时优先排除矛盾或资产问题，再测文本。生成结果和有效性没有实际证据时标为待验证。
